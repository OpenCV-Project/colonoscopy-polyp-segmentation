# 사전학습 모델 조사 (대장 내시경 용종 분할 관점)

## 1. 현재 프로젝트 적용 구성
* **세그멘테이션 아키텍처**: U-Net (`segmentation-models-pytorch`)
* **인코더(백본) 사전학습**: `ResNet-34` (ImageNet 사전학습 가중치)
  * 일반 자연 이미지로 학습된 저수준 특징(엣지, 컬러·텍스처 패턴)을 초기 특징 추출에 활용하여 학습 안정성과 수렴 속도를 높이는 역할

## 2. 주요 비교·검토 대상 사전학습 모델

| 구분 | 모델 / 아키텍처 | 핵심 특징 | 용종 분할(Polyp Segmentation) 및 프로젝트 관점 |
| :--- | :--- | :--- | :--- |
| **CNN 기반 세그멘테이션** | **DeepLabv3+** (`ResNet` 계열 백본) | ASPP(Atrous Spatial Pyramid Pooling)로 다중 스케일 문맥 정보 추출 | 크기가 다양한 용종 대응에 유리하며, 팀 내 비교 실험 모델로 활용 가능 |
| **의료 용종 특화 모델** | **PraNet** (Parallel Reverse Attention Network) | Reverse Attention 메커니즘으로 경계 영역 디테일 정교화 | 용종 경계가 흐릿하거나 주변 점막과 구분이 어려운 케이스에서 강점 |
| **Transformer / 하이브리드** | **SegFormer** (`MiT-B0` ~ `B5`) | 계층형 Vision Transformer 인코더 + 경량 디코더 | 전역 문맥(global context) 파악에 유리하며 배경 점막 오탐 비교 대상 |
| **하이브리드 인코더** | **TransUNet** | ViT 인코더 + U-Net 디코더(skip connection) 결합 | 전역 문맥과 미세 경계 복원을 함께 노리는 구조 |
| **범용 비전 파운데이션** | **SAM / MedSAM** | 대규모 세그멘테이션 데이터 기반 파운데이션 모델 | 프롬프트 기반 분할·제로샷/적응 가능성을 살피는 최신 트렌드 검토용 |

## 3. 교수님 보고 및 향후 검토 포인트
1. **사전학습 도메인 차이**: ImageNet 기반 일반 비전 사전학습과 의료·내시경 도메인 기반 가중치/모델 간 특성 차이 비교
2. **구조적 트레이드오프**:
   * **CNN 계열(U-Net, DeepLabv3+)**: 구현·학습이 직관적이고 리소스 관리가 수월함
   * **Transformer / 하이브리드 / 특화 모델**: 전역 문맥이나 경계 세밀도는 장점이 있으나 추가 라이브러리·가중치 호환성과 연산 비용 검토 필요
3. **현실적 적용 기준**: 현재 코랩 환경 및 데이터셋 규모에서 재현성·학습 시간·성능 균형을 기준으로 우선순위 선정
